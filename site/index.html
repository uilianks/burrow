Burrow

Your notes, in a folder
on your own computer.

Burrow is a block-based notes app for Windows and Linux. No accounts, no cloud, nothing sent anywhere — just pages you can see, copy and back up yourself.

Download for Windows 64-bit · .zip Download for Linux 64-bit · AppImage

On Windows: Burrow isn't code-signed yet, so Windows may say it “protected your PC” when you open it. That's expected for a new app — click More info → Run anyway.

Free and open source under the MIT licence · All releases

Everything a page needs

Write in blocks, link your thinking together and organise it however you like.

Blocks

Headings, to-dos, toggles, callouts, code with syntax colouring, tables, columns, images, video, math and Mermaid diagrams — one / away.

Databases

Rows with typed properties shown as a table, board, calendar, gallery, timeline or chart, with formulas, relations and automations.

Linked pages

Link pages with [[, see backlinks on every page and explore how it all connects in the graph view.

Fast to drive

Markdown shortcuts as you type, and Ctrl+K to search every page or run any command.

Never lose a thing

Page history keeps versions as you edit, deleted pages go to the Trash, and undo goes as far back as you need.

Make it yours

Light and dark themes, accent colours, fonts and page widths — plus plugins that add commands and block types.

Your files, not ours

Everything lives in Documents/Burrow (or any folder you choose). Copy it to a USB stick, put it in your own backup or sync tool, or open the Markdown copy in any editor. If you ever stop using Burrow, your notes are still right there.

Burrow/ ├─ burrow.json every page and block ├─ burrow.json.bak last known good copy ├─ attachments/ your uploaded files ├─ plugins/ └─ Markdown/ a readable .md of each page

Getting started

No installer wizard, no sign-up.

Windows

  1. Download Burrow-windows.zip and extract it.
  2. Open Burrow.exe.
  3. If SmartScreen warns about an unknown app, choose More info → Run anyway.

Linux

  1. Download Burrow-linux.AppImage.
  2. Make it executable and run it: 
    chmod +x Burrow-linux.AppImage
./Burrow-linux.AppImage
